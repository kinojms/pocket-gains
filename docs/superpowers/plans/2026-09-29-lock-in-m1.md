# Lock In — M1 (Playable Loop + Basic Pet) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an installable PWA the user can train with daily: onboarding → deal a balanced hand of exercise cards → warm-up → tutorial → set ⇄ rest → summary, with every set logged locally and synced to Supabase, and a basic pixel pet that gains XP and levels.

**Architecture:** React + Vite + TypeScript SPA with hash routing, deployed to GitHub Pages under `/lock_in/`. All training rules live in pure TypeScript modules under `src/domain/` (no React, no storage) and are unit-tested first. Data is local-first (Dexie/IndexedDB), synced to Supabase Postgres (RLS, single user) through a small `Remote` interface; when no Supabase env vars are set the app runs in **local mode** (no login, no sync), which is also how E2E tests run.

**Tech Stack:** React 19, Vite, TypeScript, react-router (v7, hash router), Dexie 4, @supabase/supabase-js v2, vite-plugin-pwa, Vitest + Testing Library + fake-indexeddb, Playwright, GitHub Actions + GitHub Pages.

**Spec:** `docs/superpowers/specs/2026-09-29-lock-in-design.md`

**Scope:** M1 only. M2 (weekly plan, streaks, reminders, progress charts), M3 (card levels, unlocks, placement test) and M4 (pet body mirroring, milestones) each get their own plan after the previous milestone is in use.

## Global Constraints

- Frontend base path is exactly `/lock_in/` (Vite `base`, manifest `start_url` and `scope`); the GitHub repo must be named `lock_in`.
- Routing is hash-based (`createHashRouter`); no route may depend on server rewrites.
- Only public-safe values may be committed: Supabase URL, Supabase anon key. Never commit a service-role key.
- Auth is Supabase **email + password** (no magic links/OAuth — their redirects put tokens in the URL hash, which collides with hash routing).
- Domain modules (`src/domain/**`) must not import React, Dexie, Supabase or `src/content` at module level except `src/content/sources.ts` types; they receive content/history as arguments.
- Every user write goes to IndexedDB first; network is never on the critical path of a workout.
- IDs are client-generated UUIDs (`crypto.randomUUID()`); remote writes are upserts (idempotent).
- Timers use wall-clock timestamps (`Date.now()`), never tick counting.
- Safety copy: guidance is "general fitness information, not medical advice"; never present defaults as personalized coaching.
- TypeScript template flags are kept (`verbatimModuleSyntax`, `erasableSyntaxOnly`, `noUnusedLocals`): use `import type` for types, no `enum`, no parameter properties; Dexie table fields use `declare`.
- Node 22 LTS in CI.

### Deliberate M1 deviations from the spec (reviewers: these are intended)

| Spec item | M1 behavior | Why |
|---|---|---|
| `session.status` = complete / partial / abandoned | Adds `in_progress` (local + DB check constraint) | Needed for resume; finalized to partial/abandoned after 12 h |
| `session` columns | Adds `hand jsonb` | Needed for resume and "don't repeat last hand" |
| Home: streak + today's planned deck | No streak (M2). Suggested deck = rotation `push → lower → pull → lower` by count of finished sessions | `weekly_plan` and streaks arrive in M2 |
| "This hurts" → easier variation next time | Recommender deals one step easier in that chain next time the chain is dealt | Minimal version without `card_state` (M3) |
| 😴 repeated end-early → "move reminder time" | Message suggests training earlier / sleep; reminder link arrives in M2 | Reminders are M2 |
| 💪 repeated end-early → "repeat an on-ramp week" | Message only; the existing "too hard → one fewer set next session" rule still applies | Keeps on-ramp math simple in M1 |
| Curated YouTube embeds | Link out to curated URL if present, else a YouTube search for "<name> proper form" | URLs must be human-curated, never invented |
| `VariationChain.unlockRule {sets, reps}` | `unlockRule {sets}`; reps = top of the current step's `repRange` | Steps in one chain have different ranges |
| Playwright offline → sync test | Unit test against a fake `Remote` (Task 9) | CI has no Supabase instance |

## Review Focus

1. **Phone locks or the app is backgrounded during rest** → on return the rest timer shows the true remaining time (or has finished), never a frozen/rewound value. Pinned in Task 6 (`remainingMs` test) and Task 14 (auto `REST_DONE` when remaining hits 0).
2. **App is killed mid-set and reopened** → the same card, set number and phase are restored; after 12 h the session is finalized as `partial` (or `abandoned` if no sets). Pinned in Task 8 (`recoverStaleSession` tests).
3. **Equipment can't fill a deck's slots (bodyweight-only on Pull)** → a full hand of distinct cards is still dealt from other movements; never a duplicate, never a dumbbell card. Pinned in Task 5 (content-wide deal test).
4. **Double-tapping "Log set"** → exactly one set is logged. Pinned in Task 6 (`LOG_SET` ignored outside `set` phase).
5. **Sync fails halfway and is retried** → nothing is lost and nothing is duplicated; rows stay dirty until their own upsert succeeds. Pinned in Task 9.
6. **Service worker scope under `/lock_in/`** → installed app opens at `/lock_in/` and works offline. Pinned in Task 17 (E2E checks manifest scope/start_url) and Task 18 (manual on-device check).

```ts
/** FNV-1a 32-bit */
export function hashString(s: string): number {
  let h = 2166136261
  for (let i = 0; i < s.length; i++) {
    h ^= s.charCodeAt(i)
    h = Math.imul(h, 16777619)
  }
  return h >>> 0
}

export function mulberry32(seed: number): () => number {
  let a = seed >>> 0
  return () => {
    a = (a + 0x6d2b79f5) >>> 0
    let t = a
    t = Math.imul(t ^ (t >>> 15), t | 1)
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61)
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296
  }
}

export function shuffled<T>(items: readonly T[], rand: () => number): T[] {
  const a = [...items]
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1))
    ;[a[i], a[j]] = [a[j], a[i]]
  }
  return a
}
```

```ts
import type { Content, Deck, Equipment, Exercise, Movement, VariationChain } from '../domain/types'
import exercisesJson from './exercises.json'
import chainsJson from './chains.json'
import decksJson from './decks.json'
import imagesJson from './images.generated.json'

const exerciseList = exercisesJson as unknown as Exercise[]
const chainList = chainsJson as unknown as VariationChain[]

export const content: Content = {
  exercises: Object.fromEntries(exerciseList.map((e) => [e.id, e])),
  chains: Object.fromEntries(chainList.map((c) => [c.id, c])),
  decks: decksJson as unknown as Deck[],
}

export function chainMovement(chain: VariationChain, c: Content = content): Movement {
  return c.exercises[chain.steps[0]].movement
}

export function chainEquipment(chain: VariationChain, c: Content = content): Equipment {
  return c.exercises[chain.steps[0]].equipment
}

const withImages = new Set<string>(imagesJson as string[])

export function imageUrl(exerciseId: string): string | null {
  return withImages.has(exerciseId) ? `${import.meta.env.BASE_URL}exercises/${exerciseId}.jpg` : null
}

export function videoUrl(ex: Exercise): string {
  return ex.videoUrl ?? `https://www.youtube.com/results?search_query=${encodeURIComponent(`${ex.name} proper form`)}`
}
```

- [ ] **Step 3: Create `scripts/fetch-exercise-images.mjs`**

```js
import { mkdir, readFile, writeFile } from 'node:fs/promises'

const RAW = 'https://raw.githubusercontent.com/yuhonas/free-exercise-db/main'
const map = JSON.parse(await readFile(new URL('./image-map.json', import.meta.url), 'utf8'))
const exercises = JSON.parse(await readFile(new URL('../src/content/exercises.json', import.meta.url), 'utf8'))

const res = await fetch(`${RAW}/dist/exercises.json`)
if (!res.ok) throw new Error(`dataset download failed: HTTP ${res.status}`)
const dataset = await res.json()
const byId = new Map(dataset.map((d) => [d.id, d]))

const problems = []
for (const ex of exercises) {
  if (ex.movement === 'warmup') continue
  if (!(ex.id in map)) {
    problems.push(`${ex.id}: missing from image-map.json (use null for "no image")`)
    continue
  }
  const dsId = map[ex.id]
  if (dsId !== null && !byId.has(dsId)) {
    const words = ex.name.toLowerCase().split(/[^a-z]+/).filter((w) => w.length > 2)
    const candidates = dataset
      .filter((d) => words.some((w) => d.name.toLowerCase().includes(w)))
      .slice(0, 10)
      .map((d) => `${d.id} ("${d.name}")`)
    problems.push(`${ex.id}: "${dsId}" not in dataset. Candidates: ${candidates.join(', ') || 'none, so use null'}`)
  }
}
if (problems.length) {
  console.error(problems.join('\n'))
  process.exit(1)
}

await mkdir(new URL('../public/exercises/', import.meta.url), { recursive: true })
const downloaded = []
for (const [ourId, dsId] of Object.entries(map)) {
  if (dsId === null) continue
  const path = byId.get(dsId).images[0]
  const r = await fetch(`${RAW}/exercises/${path}`)
  if (!r.ok) throw new Error(`${ourId}: image download failed: HTTP ${r.status}`)
  await writeFile(new URL(`../public/exercises/${ourId}.jpg`, import.meta.url), Buffer.from(await r.arrayBuffer()))
  downloaded.push(ourId)
}
downloaded.sort()
await writeFile(
  new URL('../src/content/images.generated.json', import.meta.url),
  JSON.stringify(downloaded, null, 2) + '\n',
)
const fallbacks = Object.values(map).filter((v) => v === null).length
console.log(`Downloaded ${downloaded.length} images; ${fallbacks} exercises use the pixel fallback.`)
```
